# Preflight Pro — 入稿データチェック・校正ツール

印刷所へ入稿する前のデータを、手元のブラウザだけで校正・プリフライトチェックするWebアプリです。
**解析はすべてクライアントサイド (ブラウザ内) で実行**され、データが外部サーバーへ送信されることはありません。

## 対応入稿形式

| 形式 | 解析方法 |
|------|---------|
| PDF | pdf.js レンダリング + バイトレベル解析 (ストリーム展開) + コンテンツストリーム解釈 |
| Illustrator (.ai) | PDF互換形式で保存されたものをPDFとして解析 |
| JPEG | バイナリメタデータ解析 (SOF / JFIF / ICC / Adobe APP14) |
| PNG | バイナリメタデータ解析 (IHDR / pHYs / iCCP) |

## チェック項目

### カラーモード
- **RGBオブジェクト検出** — DeviceRGB / CalRGB 色空間、`rg`/`RG` オペレータ (エラー/注意は設定で選択)
- ICCベースRGB色空間の疑い検出
- 特色 (スポットカラー / Separation / DeviceN) の検出
- PDF/X 準拠情報 (出力インテント)

### インキ・オーバープリント
- **総インキ量 (TAC) チェック** — 上限 250〜350% を選択可
  - ベクター塗り: コンテンツストリームの生CMYK値から**正確に**判定
  - 画像・全体: レンダリング結果からの近似判定 + ヒートマップ表示 (参考値)
- **4色ベタ (C100 M100 Y100 K100)**・レジストレーションカラーの検出
- 3色高濃度ベタの警告
- 文字へのリッチブラック使用の警告
- **オーバープリント (ノセ) 設定の検出** — `/OP` `/op` `/OPM`
- **白ノセ (白オブジェクト+オーバープリント) の疑い検出** — 印刷時に消える事故の防止

### 塗り足し・仕上がりサイズ
- TrimBox / BleedBox / MediaBox の解析
- **塗り足し幅の判定** (3mm推奨、設定可)
- 仕上がりサイズと注文サイズの一致確認
- ページサイズ混在の検出
- 2D校正ビューで**仕上がり線・塗り足し領域・文字安全域**をオーバーレイ表示

### 画像解像度
- **配置画像の実効解像度** — CTM追跡により配置サイズから実効dpiを算出 (最低dpi設定可)
- 低解像度画像の位置を2Dビューでハイライト
- ラスタ入稿時: 指定サイズ+塗り足しに対する実効解像度判定

### フォント
- 未埋め込みフォントの検出

### その他
- 暗号化 (セキュリティ設定) の検出
- 透明効果の使用情報
- 注釈・フォームフィールドの検出
- レイヤー (OCG) の検出
- 極細線 (ヘアライン 0.25pt未満) の検出
- PDFバージョン

## プレビュー

- **3Dプレビュー** — 断裁後の仕上がりを紙としてドラッグ回転・ズーム・表裏反転 (graphic のスマートチェック風)
- **2D校正ビュー** — ガイド (仕上がり線/塗り足し/安全域)、インキ量ヒートマップ、低解像度画像マーカー

## 開発

```bash
npm install       # postinstall で pdf.js worker を public/ にコピー
npm run dev       # http://localhost:3000
npm test          # フィクスチャ生成 + Playwright スモークテスト
npm run build     # プロダクションビルド
```

## Vercelへのデプロイ

そのままVercelにインポートするだけでデプロイできます (Framework: Next.js を自動検出)。

- 解析は全てクライアントサイドのため、サーバーレス関数のサイズ/実行時間制限の影響を受けません
- `postinstall` が pdf.js worker を `public/` に配置します
- 環境変数等の設定は不要です

## 制限事項

- 総インキ量のピクセル判定はRGBレンダリングからの近似です (ベクターのCMYK指定値は正確)。CMYK画像の正確なTACはPhotoshop等でご確認ください
- .ai ファイルは「PDF互換ファイルを作成」で保存されている必要があります
- オーバープリントプレビュー (分版シミュレーション) は未実装です
- 本ツールは入稿前セルフチェック用であり、印刷所の正式なデータチェックを代替するものではありません
